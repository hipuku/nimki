title: Introduction
description: React components for product interfaces, a drop-in superset of shadcn/ui with designed motion.
---

nimki keeps shadcn/ui's component names, parts and props, so a shadcn project can swap a component in without changing how it is used. Each component adds motion designed for it, from one set of motion tokens, and the additions shadcn lacks.

Nothing is released yet. Version 0 is Button, Input with Label, Select, Switch, Tabs and Dialog.

## Using these docs

The controls at the top of every page set the colour mode, the motion theme, the density and reduced motion. Every demo follows them, so a component can be checked in each combination. Your choices are kept in this browser.

## What is here

- [Motion](/docs/foundations/motion): every motion role in every theme, drawn and played side by side.
- [Select](/docs/components/select): the first component, in design. Its page shows the layout every component page follows.
