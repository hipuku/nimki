Components never pick a duration or a curve themselves. Each moving part names a role, such as `popover-enter` or `highlight`, and the role's tokens decide how it moves. The values here come from the same generated tokens the components run, so this page cannot drift from them.

## Themes

There are two motion themes and one reduced mode.

- **Expressive**: a little longer, with a small bounce on the springs.
- **Subtle**, the default: short, no bounce.
- **Reduced**: used when the system asks for reduced motion or the Reduced motion control is on. Nothing travels: overlays fade in place within 120 ms, and anything that would move jumps.
