## Installation

<Install name="select" />

Select reads nimki's token CSS, which the command installs with it under `styles/nimki/`. Import those files in the project's global CSS after Tailwind:

```css
@import 'tailwindcss';
@import './styles/nimki/extensions.css';
@import './styles/nimki/tailwind.css';
@import './styles/nimki/motion.css';
@import './styles/nimki/density.css';
```

## Usage

The same API as shadcn's Select: the same parts, names and props.

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectTrigger,
  SelectValue,
} from '@/components/ui/select'

export function FruitSelect() {
  return (
    <Select>
      <SelectTrigger className="w-48">
        <SelectValue placeholder="Select a fruit" />
      </SelectTrigger>
      <SelectContent>
        <SelectGroup>
          <SelectLabel>Fruit</SelectLabel>
          <SelectItem value="apple">Apple</SelectItem>
          <SelectItem value="banana">Banana</SelectItem>
          <SelectItem value="blueberry">Blueberry</SelectItem>
        </SelectGroup>
      </SelectContent>
    </Select>
  )
}
```

It is built on Base UI, with a thin layer that keeps shadcn's Radix-style API: `asChild` on every part that takes it, `onValueChange` and `onOpenChange` with Radix's single argument, `position`, and `onEscapeKeyDown`, `onPointerDownOutside` and `onCloseAutoFocus` on the content.

### Where it differs from shadcn's

- **The list opens below the trigger.** `position` defaults to `"popper"`, as designed; `position="item-aligned"`, shadcn's default, lays the chosen option over the trigger instead.
- **A disabled option can be highlighted.** The arrow keys move onto it, so a screen reader announces it, but it cannot be chosen. This follows the WAI-ARIA Authoring Practices; Radix skips it instead.
- **A group with no options shows nothing,** its label included.

## Accessibility

- The trigger is a combobox that says whether its list is open; the list is a listbox named after the trigger.
- Each option says whether it is selected. A disabled option is announced but cannot be chosen.
- Focus returns to the trigger when the list closes.
- Name the trigger with a `Label`, or `aria-label` when there is no visible one.
- Every state is checked with axe in light and dark, in Chromium, Firefox and WebKit.
